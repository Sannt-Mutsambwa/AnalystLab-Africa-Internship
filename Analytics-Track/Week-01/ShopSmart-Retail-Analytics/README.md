# ShopSmart Retail Analytics | Week 1

## Project Overview

This project is part of my Week 1 assignment for the Data Analytics Track at AnalystLab Africa.

The aim was to analyse ShopSmart's retail data using Microsoft Excel and understand how the business performed in 2025.

## Tools Used

- Microsoft Excel
- Excel formulas
- XLOOKUP
- PivotTables
- PivotCharts

## What I Worked On

- Cleaning and organising the datasets
- Calculating sales figures using Excel formulas
- Using XLOOKUP to connect data from different worksheets
- Analysing sales by month, product category, store and customer
- Looking at product returns
- Creating an executive dashboard

## Key Findings

- ShopSmart recorded about 7.58 billion in sales value.
- Beauty was the highest-performing product category.
- December had the highest monthly revenue.
- Lagos was the highest-performing state.
- The overall return rate was 5%.

## Limitations

Some business questions could not be fully answered.

There was no clear link between the Products and Suppliers datasets.

The sales figures are based on recorded order-item values and do not automatically account for refunds or cancelled orders.

## What I Learned

This assignment helped me practise using Excel to work with a large dataset.

I also learned more about how PivotTables and charts can be used to understand business performance.

There is still a lot for me to learn, but this project gave me more experience working with retail data.
